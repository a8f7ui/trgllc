# Technology Research Group

Official website source for **Technology Research Group**, a US-based organization focused on applied technology research, field testing, evaluation, and evidence-based recommendations.

Website: https://www.techresearchgroupllc.com

---

## About

Technology Research Group conducts practical research and evaluation intended to help organizations better understand emerging technologies and make informed decisions.

The website presents general information about the organization, its areas of focus, research approach, and contact information.

---

## Repository Contents

This repository contains the source files used to operate the Technology Research Group website, including:

- `index.html` — primary website page
- `privacy.html` — website privacy policy
- `terms.html` — website terms of use
- `assets/` — website images, logos, and other static assets

The repository is configured for deployment through GitHub Pages.
